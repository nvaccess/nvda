On-device OCR

This add-on recognizes text in the current NVDA navigator object with a local PP-OCRv6 model.

Use

  1. Move the navigator object to a visible window, control, or image.
  2. Press NVDA+Alt+O. NVDA says “Recognizing”. The first use downloads and verifies the selected model.
  3. Read the result with speech, braille, or cursor keys. Press Escape to return.

Choose Tiny or Small and automatic reading under NVDA Settings > On-device OCR. Tiny is the fastest default for Chinese, English, Traditional Chinese, and common Latin scripts. Small adds Japanese and can be more accurate but uses more memory.

Privacy and files

After the first model download, recognition is offline. Captured images are not uploaded. Temporary frame files are deleted after success, failure, and cancellation. Models are stored in %LOCALAPPDATA%\nvda\onDeviceOcr\models and verified by SHA-256.

Limitations

The current pipeline targets horizontal desktop UI text and retries low-confidence text skewed by 2–15 degrees. Vertical, handwriting, strongly perspective, arbitrary-angle, and complex multi-column text can be inaccurate. The separate OCR process closes after the configured idle period.
