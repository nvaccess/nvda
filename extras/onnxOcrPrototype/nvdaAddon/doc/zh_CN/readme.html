设备端 OCR

本插件使用本地 PP-OCRv6 模型，识别 NVDA 当前浏览对象中的文字。

使用方法

  1. 把浏览对象移动到可见的窗口、控件或图片。
  2. 按 NVDA+Alt+O。NVDA 会提示“正在识别”。第一次使用时会下载并校验所选模型。
  3. 可通过语音、盲文或方向键阅读结果；按 Escape 返回。

在 NVDA 设置 > 设备端 OCR中可选择 Tiny 或 Small 模型，并设置是否自动朗读。Tiny 是速度最快的默认模型，适合简体中文、繁体中文、英文和常用拉丁文字；Small 额外支持日文，准确率可能更高， 但占用内存也更多。

隐私和文件

模型下载完成后，识别过程完全离线，截图不会上传。成功、失败或取消后都会删除临时图像。模型保存在 %LOCALAPPDATA%\nvda\onDeviceOcr\models，并通过文件大小和 SHA-256 校验。

已知限制

当前流程主要针对桌面界面的水平文字，并会对置信度较低、倾斜 2–15 度的文字自动纠偏重试；竖排文字、 手写体、强透视、任意角度旋转和复杂多栏排版的识别效果仍可能不佳。OCR 独立进程会在设置的空闲时间后退出。
